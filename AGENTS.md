# Live CAD development rules

- Report progress and user-facing QA in Lao unless the user requests another language.
- Prefer `tools/live_plan/` for requests whose result must be editable and visible directly in AutoCAD 2025. Temporary JSON/LISP files are internal; do not substitute a file handoff for the live result.
- Inspect the current SketchUp model/session/units and AutoCAD drawing/units before drawing. Attach to `AutoCAD.Application.25`; a structural/read-only MCP health check does not establish drawing capability.
- Preserve existing drawings and entities. Live drawing creates a new empty unsaved drawing; saving to a new output path is explicit opt-in; never overwrite or erase the active existing drawing. Never automatically retry `Add`, `SendCommand`, `SaveAs`, or other mutations after an ambiguous response or timeout. Reconcile actual state first.
- Use actual source face/edge geometry. No bounding-box substitution for walls, openings, or room dimensions. Rectangle revisions are permitted only after validating all actual cut edges form that rectangle. Unsupported geometry stays explicit and unverified.
- The originating workflow uses user-approved 100 mm masonry. For other projects, require explicit `wall_thickness_mm` and `revision_evidence`; do not silently impose it. Keep axes unless the user approves specific axis changes; preserve glass, columns, and concrete ramp walls. Require explicit source classification/exclusions.
- Actual Draw Order: other geometry behind wall fills, wall outlines above their fills, column fills above walls, column outlines above their fills. Layer-list sorting does not establish this order.
- Add only verified grids, labels, room names and witness points. Set native dimension text/arrow sizes explicitly; current DIMTXT variables alone do not reliably configure COM-created dimensions. Do not overwrite dimension values with text. Distinguish masonry openings from usable passage widths.
- After revisions, inspect actual CAD entities and visible model close-ups, not only generated code. Check wall/column junctions, thickness, protrusions, gaps, overlaps, hatch holes, openings, access elements, layers, lineweights, linetypes, Draw Order, annotation collisions, and dimensions.
- For sheets, inspect paper size, viewport scale/lock, duplicate viewports, clipping, title/revision information and actual Plot Preview. Missing visual evidence is UNVERIFIED, not PASS. Geometry cannot establish hinge/swing, usable passage, accessibility or structural adequacy by itself.
- Do not save unless the user explicitly requests it. Zoom Extents, verify counts/layers/units and representative measurements in the live document; after an explicitly requested save, verify again, and leave the intended result open in AutoCAD. Keep QA receipts with PASS/FAIL/UNVERIFIED/N/A and reasons in the ignored work directory.
- Do not commit model geometry, DWG/SKP files, screenshots, connection tokens, credentials, local session IDs or machine-specific source paths. Only synthetic fixtures belong in tests/examples.
- Validate changes with `python -m unittest discover -s tests -v` and the offline synthetic `prepare` command. Live integration tests must use a new synthetic drawing/output, preserve all existing documents, and restore the user's intended drawing afterward. Do not claim Windows live integration based solely on offline tests.
