# ກົດການສ້າງໂມເດວ SketchUp (Model convention)

ເຄື່ອງມືອ່ານ "ຄວາມໝາຍ" ຈາກ **ຊື່ component**. ໂມເດວທີ່ຕັ້ງຊື່ຕາມນີ້ ຈະໄດ້ຊຸດແບບຄົບໂດຍບໍ່ຕ້ອງແກ້ໂຄດ
(ຕົວຢ່າງທີ່ດີ: Seathis Office `model.skp`).

## 2. Component ລູກ = ລາຍການ (ລະຫັດປະເພດ-ເລກ ຊື່)
ຮູບແບບ: `<TYPE>-<NN> <ຄຳອະທິບາຍ>` ເຊັ່ນ `C1-03 ຄໍເສົາຫຸ້ມ (C1)`, `GF-04 ຝາກະຈົກໜ້າຫ້ອງການ`, `DL-12 ໂຄມດາວໄລທ໌`.
- `<TYPE>` ກາຍເປັນ tag/ລະຫັດໃນຕາຕະລາງ (ປະເພດດຽວກັນ ຂະໜາດຕ່າງ → GF1, GF2 …).
- ເສົາ (ໃນ 04): ໜ້າຕັດ ≤ 600 mm, ສູງ > 1.5 m → ໃຊ້ສ້າງ grid ແລະ ຕຳແໜ່ງຮູບຕັດ (ກາງຊ່ອງເສົາ).
- ປະຕູ/ປ່ອງຢ້ຽມ: 1 component ຕໍ່ 1 ຊ່ອງເປີດ (ກວ້າງ ແລະ ສູງ ≥ 300 mm); ຊິ້ນສ່ວນນ້ອຍ (ກອບ) ຖືກຂ້າມ.

## 3. ອື່ນໆ
- ຫົວໜ່ວຍ mm; ພື້ນດິນທຳມະຊາດ ±0.00 ຢູ່ Z = 0.
- ແກນຍາວຂອງອາຄານ ຕາມ X ຫຼື Y ກໍໄດ້ (ແຜນຜັງຈະໝຸນໃຫ້ຍາວຕາມແຜ່ນເອງ); +Y = ທິດເໜືອ.
- ກະຈົກ: material opacity < 95% → ເບິ່ງທະລຸໄດ້ໃນຮູບດ້ານ.
- ຮູບຕັດ: ໃສ່ Section Plane ໃນໂມເດວ ເພື່ອກຳນົດເອງ; ບໍ່ມີ → A-A / B-B ອັດຕະໂນມັດ.
- Tag/Layer ທີ່ປິດ (hidden) ຈະບໍ່ຖືກແຕ້ມ.
