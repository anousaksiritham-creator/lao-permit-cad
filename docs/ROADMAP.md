# Roadmap — ວິເຄາະຊ່ອງຫວ່າງ ຈົນເຖິງເປົ້າໝາຍ

## ເປົ້າໝາຍ
ເປີດໂມເດວ SketchUp → ສັ່ງ 1 ຄຳສັ່ງ → ໄດ້ **ຊຸດແບບ A3 ຄົບ** (ສະຖາປັດ A, ໂຄງສ້າງ B, ໄຟຟ້າ E, ນ້ຳ P)
ໃນ AutoCAD ຕາມມາດຕະຖານ `STANDARD.md`, ພ້ອມ PDF ສຳລັບຍື່ນຂໍອະນຸຍາດ/shop drawing, ແກ້ດ້ວຍມືໜ້ອຍທີ່ສຸດ.

**ເກນວັດຜົນ (Definition of Done)**
1. ແຜ່ນທັງໝົດໃນ index (A101…P401) ຖືກສ້າງ, ເລກແຜ່ນ/ຊື່/scale ກົງກັບ index 100%.
2. ແຜນຜັງ/ຮູບດ້ານ/ຮູບຕັດ ບໍ່ມີເສັ້ນທີ່ຖືກບັງ, ມີ cut ໜາ / beyond ບາງ, layer ຖືກຕາມປະເພດ.
3. ມີ grid, dimension, ລະດັບ, tag ປະຕູ-ປ່ອງຢ້ຽມ, ຊື່ຫ້ອງ, callout ວັດສະດຸ ອັດຕະໂນມັດ.
4. ຂະໜາດໃນແບບ ກົງກັບໂມເດວ (ກວດອັດຕະໂນມັດ ±1 mm).
5. Plot PDF A3 ຄົບຊຸດ; ການແກ້ດ້ວຍມື < 10% ຂອງເວລາແຕ້ມເອງ.

### ສິ່ງທີ່ຍັງຄ້າງ (ລຽງຕາມຄວາມສຳຄັນ)
1. ທົດສອບກັບໂມເດວອື່ນ (ອາຄານ 2 ຊັ້ນ, ຫຼັງຄາຈົ່ວ) → ແຜນຜັງຫຼາຍຊັ້ນ (cut ຕໍ່ຊັ້ນ), ລະດັບຫຼາຍຊັ້ນ.
2. ຊື່ຫ້ອງ + ພື້ນທີ່ m² (ຕ້ອງມີ group ຫ້ອງ `R:<ຊື່>` ໃນໂມເດວ).
3. Hatch ວັດສະດຸໃນຮູບຕັດ (ຄສລ, ດິນຈີ່, ດິນ) ຈາກ cut loops.
4. Library ຮູບຂະຫຍາຍມາດຕະຖານ (B3xx–B7xx, P3xx) ເປັນ DWG block → ແຊກເຂົ້າຕາມລະຫັດ (C1, GB1 …).
5. ໄຟຟ້າ: ສັນຍາລັກມາດຕະຖານແທນ outline, ວົງຈອນ, ຕາຕະລາງໂຫຼດ.
6. ຂໍ້ຄວາມຊ້ອນກັນ: ກວດ bbox ຂອງ tag/text ແລ້ວເລື່ອນອັດຕະໂນມັດ.
7. ຍັງບໍ່ທັນມີ: plot ຜ່ານ layout/viewport (ປັດຈຸບັນ plot window ໃນ Model space).

### 2. ມາດຕະຖານການສ້າງໂມເດວ SketchUp (input contract)
ຄຸນນະພາບແບບ ຂຶ້ນກັບໂມເດວ. ຕ້ອງກຳນົດ **ກົດການຕັ້ງຊື່** ໃຫ້ໂມເດວທຸກອັນ (Seathis ເຮັດໄດ້ດີແລ້ວ):
- Component ລະດັບເທິງ ມີ code `NN ຊື່` (00–20) — ຂຽນເປັນ `docs/MODEL-CONVENTION.md` + mapping code → ປະເພດ → layer.
- ປະຕູ/ປ່ອງຢ້ຽມ ເປັນ component ຊື່ `D1`, `W1`… (ເພື່ອ tag + schedule).
- ເສົາ ເປັນ component ແຍກແຕ່ລະຕົ້ນ (ເພື່ອສ້າງ grid).
- ຫ້ອງ: group ພື້ນທີ່ຊື່ `R:ຫ້ອງການ` ຫຼື text ໃນ tag `ROOM`.
- ລະດັບ: attribute ໃນ model ຫຼື ອ່ານຈາກ bounds (ພື້ນ, ເພດານ, ຫຼັງຄາ).
- ວັດສະດຸ: ຊື່ material ເປັນພາສາລາວ ທີ່ຈະເອົາໄປເປັນ callout.
- Scene `A311 ຮູບຕັດ A-A` + section plane → ກຳນົດຕຳແໜ່ງຮູບຕັດ.

## ສິ່ງທີ່ຕ້ອງການຈາກຜູ້ໃຊ້
